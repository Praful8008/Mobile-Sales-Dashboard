## 🌟 Overview

The **Mobile Sales Dashboard** is a sophisticated business intelligence solution designed to provide deep insights into mobile device sales performance. Built with Power BI, this interactive dashboard transforms raw sales data into actionable business intelligence, enabling data-driven decision making for mobile retailers and manufacturers.

## ✨ Key Features

### 📊 **Comprehensive Analytics**
- 🔢 **Total Sales Overview** - Real-time revenue tracking and KPI monitoring
- 📈 **Sales Trends Analysis** - Daily, monthly, and yearly performance metrics
- 🗺️ **Geographic Distribution** - Interactive city-wise sales mapping
- 💳 **Payment Analytics** - Multi-channel payment method breakdown
- ⭐ **Customer Satisfaction** - Rating analysis and feedback insights
- 📱 **Product Performance** - Brand and model comparison reports

### 🎯 **Advanced Visualizations**
- Interactive charts and graphs
- Dynamic filtering capabilities
- Drill-down functionality
- Comparative analysis tools
- Time-series forecasting

### 📱 **Mobile Device Coverage**
- **Latest iPhone Models**: iPhone 15 series, iPhone 17 series
- **Samsung Galaxy**: S24 series (S24, S24+, S24 Ultra)
- **Popular Android Brands**: OnePlus, Vivo, Xiaomi (Mi, Redmi)

## 📋 Dataset Specifications

| **Metric** | **Details** |
|------------|-------------|
| 📊 **Total Records** | 3,985 transactions |
| 🏢 **Brands Covered** | 5 major brands (Apple, Samsung, OnePlus, Vivo, Xiaomi) |
| 📱 **Mobile Models** | 18 different models |
| 🏙️ **Cities** | Multiple metropolitan areas |
| 📅 **Time Period** | 2024-2025 |
| 💰 **Revenue Range** | $10K - $70K per unit |

### 🗂️ **Data Structure**
```
📁 Dataset Columns (14 fields):
├── Transaction ID      - Unique transaction identifier
├── Date Information    - Day, Month, Year, Day Name
├── Product Details     - Brand, Mobile Model, Units Sold
├── Financial Data      - Price Per Unit, Total Revenue
├── Customer Info       - Name, Age, Ratings (1-5 stars)
├── Location Data       - City distribution
└── Payment Method      - UPI, Cards, Cash
```

## 🚀 Quick Start Guide

### 📥 **Installation & Setup**

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Praful8008/dashboard.git
   cd Mobile-Sales-Dashboards-
   ```

2. **Open Power BI Dashboard**
   - Launch Power BI Desktop
   - Open `Mobile Sales Dashboard.pbix`
   - Refresh data connections if needed

3. **Explore the Data**
   - Review `Mobile Sales Data.xlsx` for raw data
   - Check data structure and relationships

### 🔍 **Dashboard Navigation**
- Use filters to segment data by brand, city, or time period
- Click on charts for drill-down analysis
- Hover over data points for detailed tooltips
- Export visualizations and reports as needed
